# Estrutura: mapa de blocos, motores e retenção

## 1. Ponte de interesse

Todo tema é aceito. O trabalho é tornar visível por que alguém se importaria:

> assunto → desejo, dor ou decisão → o que travava antes → o que mudou → o que a pessoa passa a conseguir → prova.

| Distância | Reparo |
|---|---|
| jargão alto | problema, diferença ou utilidade antes do nome |
| benefício abstrato | caso, contraste ou demonstração |
| resultado distante | uma vitória menor e mais próxima primeiro |
| pré-requisito alto | o mapa mínimo para começar |
| prova fraca | fonte, teste ou frase condicional |

## 2. Contrato

Escolha o nível mais forte que o vídeo consegue cumprir: clareza, decisão, ação, economia, controle ou nova perspectiva. Frase de trabalho:

> A pessoa entra com ___ e termina entendendo, decidindo ou conseguindo ___.

Se a frase ficar ampla, gere ângulos, escolha um e siga.

## 3. Motores

Escolha pelo trabalho que o espectador precisa fazer, não por template.

| Motor | Sequência | Quando |
|---|---|---|
| curso comprimido | quem está de fora → mapa finito e barato → unidades curtas encadeadas → demonstração no meio → sistema montado | assunto que assusta, entregue inteiro num tempo declarado |
| explicação | confusão → diferença central → mapa → decisões → sistema | conceito ou sistema abstrato |
| demonstração | objetivo → primeira tentativa → obstáculo → correção → resultado → como reaplicar | existe um resultado concreto |
| investigação | pergunta → critérios → teste → evidência → interpretação → limite | alegação nova ou comparação incerta |
| comparação | decisão → critérios → testes iguais → prós e contras → escolha por contexto | duas opções reais |
| diagnóstico | sintoma → causas possíveis → teste → causa provável → correção → prevenção | erro comum |
| história | estado inicial → tensão → tentativa → limite → aprendizado → novo modelo | carreira, negócio, caso real |
| desafio | regra → tentativa → obstáculos → ajustes → resultado → implicação | capacidade que parece difícil |

Combine motores só quando simplifica (ex.: curso com um projeto atravessando os blocos). Não invente falha falsa para criar drama nem detalhe autobiográfico.

## 4. Escada, não catálogo

A peça central da retenção no meio do vídeo. Cada bloco morre abrindo o próximo:

```
o básico funciona → só que ele esquece tudo
  → memória → só que ele não sabe o que você quer
  → contexto → só que tudo isso quebra quando cresce
  → organização → e é aí que vira um sistema
```

- Sair no minuto 4 significa não entender o minuto 8: é isso que segura.
- Teste: se dá para embaralhar a ordem dos blocos sem perda, é catálogo. Reagrupe por decisão ou por dependência.
- Transições são consequências, não anúncios: "só que aí aparece um problema…", "e é por isso que…", "beleza, mas e quando isso quebra?". "Agora vamos falar de…" está errado.

**Vídeo de lista ("as 7 melhores X") virando escada:** ordene por necessidade (o que a pessoa precisa primeiro), faça cada item resolver o limite do anterior e guarde o mais impressionante para quando a pessoa já entende por que ele importa.

## 5. A molécula de cada bloco

Use os elementos necessários, nesta ordem lógica:

> necessidade → resposta → exemplo ou prova → o que isso muda → limite → gancho para o próximo.

Variantes:
- **Conceito:** separar duas coisas parecidas → definir → exemplo → contraste → imagem do dia a dia → "e isso importa porque…".
- **Curto (bloco de apoio):** contraste → analogia → ação concreta → uma linha de resumo.
- **Ferramenta ou passo:** o problema que ela resolve antes do nome → o que fazer → o resultado visível → onde ela não serve (vira o gancho do próximo).

O tempo que mais some é "o que isso muda". Conceito que termina no próprio conceito soa a aula; feche amarrando a uma consequência concreta para o público do perfil.

## 6. Retenção ao longo do vídeo

Três perguntas que o espectador faz:
1. **Entrada** — é o vídeo em que cliquei? (abertura)
2. **Continuidade** — estou entendendo ou ficando mais capaz? (escada)
3. **Conclusão** — ainda tem algo que vale chegar ao fim? (final)

Quatro funções:
- **Confirmação:** assunto, promessa e diferença claros; parece do tamanho da pessoa.
- **Ativação:** uma resposta, prova ou utilidade já começou.
- **Progressão:** cada bloco aumenta a capacidade e torna o próximo necessário.
- **Integração:** o final junta as peças.

**Distância até o primeiro pagamento** — a variável mais previsível de queda. Meça em blocos:
- pagamento no primeiro bloco: confirmação forte;
- no segundo: aceitável se o primeiro montou o mapa;
- depois do terceiro: evasão, mesmo com bom gancho;
- só no final: o mistério virou enrolação.

Pagamento é resposta, diferença, prova, demonstração ou decisão. Não é promessa repetida nem contexto histórico. Se o vídeo precisa de fundamento antes, faça o fundamento ser o pagamento: mostre a coisa funcionando e explique depois.

**Concreto antes de abstrato.** "O que é → o que dá para fazer → por que muda o jogo" segura; "por que muda o jogo → o que é → o que fazer" parece mais inteligente e perde gente.

**Unidades de valor.** Contam: resposta, decisão, prova, mudança observável, correção. Não contam sozinhos: nome técnico, função, pergunta, efeito visual, promessa, suspense. Se dois blocos seguidos só acumulam nomes, corte, agrupe ou demonstre.

**Loops.** Micro (paga na mesma frase), de bloco (paga no fim da etapa) e macro (paga no final). Não esconda uma resposta curta até o fim: o loop macro existe para completar uma integração, não para segurar refém.

**Reentrada** depois de patrocínio, pedido de inscrição ou trecho denso: lembre o que foi conquistado, diga o que falta e por que a próxima etapa importa.

## 7. O bloco de risco

O lado feio entra: custo real, o que dá errado, limites, quando não usar. Quem entrega o custo ganha o direito de recomendar, e isso protege a confiança do canal.

## 8. Escopo

| Classe | Destino |
|---|---|
| essencial | corpo do vídeo |
| útil depois | menção rápida, descrição ou outro vídeo |
| avançado | depois da primeira vitória |
| decorativo | cortar |

Se a pessoa pediu uma lista completa, mantenha os itens e crie hierarquia; não corte o que foi pedido em nome da retenção.

Duração não é meta: escreva o que a escada exige e corte o resto. Para estimar, divida as palavras pelo ritmo do perfil (genérico: 160 palavras por minuto).

## 9. Final

O final entrega a consequência acumulada: sistema montado, comparação concluída, decisão justificada, resultado verificado, nova perspectiva ou primeiros passos concretos. É ação ou nova forma de ver, nunca resumo do que acabou de ser dito. O pedido de inscrição vem depois da entrega e no mesmo tom do resto do vídeo.

## 10. Patrocínio

- **Integração:** o produto entra quando a necessidade já existe no roteiro; a tese continua independente.
- **Dedicado:** o produto pode conduzir o vídeo, mantendo problema, processo, resultado e limites honestos.
- **Obrigação no começo:** cumpra de forma curta e faça reentrada.

Publicidade não transforma alegação comercial em fato.
